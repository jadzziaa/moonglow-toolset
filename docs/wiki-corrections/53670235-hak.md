# HAK

https://nwn.wiki/spaces/NWN1/pages/53670235/HAK, edit written against version 4. Unchanged on nwn.wiki as of the mirror's sync of 2026-10-26.

## Edit summary

File Size Limits: the 2GB limit applies to the game too, not only the Toolset and nwsync.

## Change 1

**Find** ("File Size Limits"):

> However it should be noted that you should keep hakpacks to less than 2GB filesize. This helps the Toolset and tools like nwsync work properly.

**Replace with:**

> However it should be noted that you must keep hakpacks to less than 2GB filesize. The game itself doesn't read past 2GB, as well as the Toolset and tools like nwsync: a resource whose data starts at 2GB or later in a hakpack is missing in game, and a copy of it in a lower hakpack doesn't take over. See [Resource Limits](https://nwn.wiki/spaces/NWN1/pages/26738887/Resource+Limits).

## How it was checked

`engine_big_hak.rs` in Moonglow Toolset's `crates/mg-corpus-tests/tests/`: `the_game_reads_nothing_that_starts_past_2_gib_in_a_hak` and `past_2_gib_a_lower_haks_copy_doesnt_count` build sparse 2.1 GiB hakpacks with a 2da and a script before and after the 2 GiB mark, and run a module using them in the game's own server (`nwserver`, started privately). The tests read the tester's own game install.
