# GFF

https://nwn.wiki/spaces/NWN1/pages/38175366/GFF, edit written against version 5. Unchanged on nwn.wiki as of the mirror's sync of 2026-10-26.

## Edit summary

File type table: .git is Area Instanced Contents and .gic Area Instanced Comments (they were swapped).

## Change 1

**Find** (the table of GFF file types, row "Area Instanced Contents", whose Notes begin "Area file instanced content; eg: placed monsters and placeables in the area."): the File Type cell `.gic` and the Nwscript constant cell `RESTYPE_GIC`.

**Replace with:** `.git` and `RESTYPE_GIT`. The row's Notes stay as they are.

## Change 2

**Find** (the next row, "Area Instanced Comments", whose Notes begin "Area file instanced comments."): the File Type cell `.git` and the Nwscript constant cell `RESTYPE_GIT`.

**Replace with:** `.gic` and `RESTYPE_GIC`.

**Add after** "Area file instanced comments." in the same row's Notes:

> It holds one struct per placed object, in the same order as the lists in the .git.

## How it was checked

Any module's placed objects are in its areas' .git files, not the .gic. In Moonglow Toolset's `crates/mg-corpus-tests/tests/`, `aurora_instances.rs` `placed_objects_match_aurora` compares the placed objects in the .git files Aurora saved (toolset 89.8193.37 under Wine), and `aurora_new.rs` `new_modules_and_areas_match_aurora` and `aurora_update_instances.rs` `update_instances_matches_aurora` compare the .git and .gic files Aurora wrote. The tests read the tester's own game install.
