# TLK

https://nwn.wiki/spaces/NWN1/pages/38176005/TLK, edit written against version 22. Unchanged on nwn.wiki as of the mirror's sync of 2026-10-26.

## Edit summary

Custom TLKs in haks are read (haks, then module, then tlk folder); TLK is its own binary format, not GFF; the text flag.

## Change 1

**Find** (introduction):

> is a GFF file which contained the strings used by the game

**Replace with:**

> is a binary file (its own format, not a GFF file) which contains the strings used by the game

## Change 2

**Find** ("Adding a Custom TLK file to a module"):

> As usual they need to be 16 characters + .tlk extension. Tlk files placed into a hakpak won't be recognized by the game; it's as if it's not in the hak at all.

**Replace with:**

> As usual the name can be up to 16 characters; the module stores it without the .tlk extension. The game looks for the custom TLK in the module's hakpaks first, then in the module, then in the user's tlk folder. The female variant (xxxf.tlk) is looked up separately in the same order, so a TLK in a hak can pair with a female one in the tlk folder; with no female table, female lookups return the male text. The module will not load at all if the TLK is missing, if the stored name ends in .tlk, or (on Linux) if its case differs from the file's.

## Change 3

**Add after** (the end of "TLK format", after "For a module specific TLK file see below for how to reference it with the magic number."):

> An entry's text is only used when its text flag (0x1) is set. An entry with text but without the flag reads as an empty string, as does a sound-only entry and a row past the end of the table.

## How it was checked

`engine_tlk.rs` `where_the_game_reads_custom_talk_tables` in Moonglow Toolset's `crates/mg-corpus-tests/tests/`: a module whose custom TLK is in a hak, the module or the tlk folder (and in two at once), with and without a female table, named in upper case, named with .tlk, or missing, plus an entry with text but no text flag, run in the game's own server (`nwserver`, started privately), reading the strings back with a script. The tests read the tester's own game install.
